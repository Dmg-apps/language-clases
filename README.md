# Deutsch A1–B1

Herramienta privada para preparar y repasar clases de alemán.

Esta página solo contiene la aplicación: **no incluye contenido, audios ni datos de alumnos**. Todo eso está en una base de datos privada y solo se entrega a cuentas aprobadas por la profesora tras iniciar sesión.

- Registro con confirmación de email; las cuentas nuevas quedan pendientes hasta que la profesora las aprueba y las vincula con un alumno.
- La cuenta de la profesora exige doble factor (app de autenticación).
- Seguridad por filas en la base de datos: cada alumna solo puede leer su propia ficha.
- Política de seguridad de contenido estricta (CSP con huellas SHA-256 de cada script).
