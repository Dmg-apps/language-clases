# Deutsch A1–C2

Herramienta privada para preparar y repasar clases de alemán.

Esta página solo contiene la aplicación: **no incluye contenido, audios ni datos de estudiantes**. Todo eso está en una base de datos privada y solo se entrega a cuentas aprobadas por su docente tras iniciar sesión.

- Registro con confirmación de email; las cuentas nuevas quedan pendientes hasta que su docente las aprueba y las vincula con una ficha.
- La cuenta docente exige doble factor (app de autenticación).
- Seguridad por filas en la base de datos: cada estudiante solo puede leer su propia ficha.
- Política de seguridad de contenido estricta (CSP con huellas SHA-256 de cada script).
